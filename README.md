# GlowRay ✨ کلاینت VPN مدرن ویندوز (sing-box)

کلاینت واقعی VPN برای ویندوز با هسته **sing-box**، رابط کاربری گلو و انیمیشنی، اتصال یک‌کلیکی به بهترین سرور، پروکسی سیستم و تونل کامل (TUN).

## امکانات
- لیست کانفیگ‌ها خودکار از ساب‌اسکریپشن (Gist شما) دریافت می‌شود؛ از ساب base64 و چند لینک هم پشتیبانی می‌کند
- پروتکل‌ها: VLESS (TLS / Reality / Vision) ، VMess ، Trojan ، Shadowsocks ، Hysteria2 ، TUIC
- ترنسپورت‌ها: TCP ، WS (با early-data مثل `?ed=2560` ورکرهای کلادفلر) ، gRPC ، HTTPUpgrade ، H2
- **دکمه اتصال یک‌کلیکی**: اول پینگ TCP همه سرورها، بعد تست *واقعی* (از داخل تونل با `generate_204`) و انتخاب سریع‌ترین. گروه urltest هر ۳ دقیقه دوباره تست می‌کند و اگر سرور افتاد، خودکار عوض می‌شود
- **پروکسی سیستم** (mixed HTTP/SOCKS روی `127.0.0.1:10808`) + **TUN** برای کل سیستم (همه برنامه‌ها و بازی‌ها)
- عوض کردن سرور حین اتصال بدون قطعی، نمایش سرعت دانلود/آپلود زنده، نمودار، تایمر، لاگ
- کانفیگ ناسازگار به‌صورت خودکار با `sing-box check` حذف می‌شود تا اتصال خراب نشود
- DNS امن (DoH از طریق تونل)، گزینه Bypass Iran (سایت‌های ایرانی مستقیم)
- اگر برنامه کرش کند، دفعه بعد پروکسی سیستم خودکار پاک می‌شود
- مخفی شدن در System Tray

## اجرا (حالت توسعه)
۱. [Node.js LTS](https://nodejs.org) را نصب کنید
۲. در پوشه پروژه: `run-dev.bat` (یا `npm install` و بعد `npm start`)

هسته sing-box اگر نباشد، در اولین اتصال خودکار از GitHub دانلود می‌شود. برای اینکه داخل exe باشد: `npm run core`

## ساخت فایل exe
`build.bat` را اجرا کنید. خروجی در پوشه `dist`:
- `GlowRay-Setup-1.0.0.exe` (نصب‌کننده)
- `GlowRay-Portable-1.0.0.exe` (پرتابل)

بدون نصب هیچ چیز: پروژه را در GitHub پوش کنید؛ ورک‌فلو `.github/workflows/build.yml` خودش exe را می‌سازد (تب Actions > Artifacts).

## نکات
- حالت **TUN** دسترسی Administrator می‌خواهد؛ برنامه خودش می‌پرسد و با دسترسی ادمین دوباره اجرا می‌شود
- لینک ساب را از ⚙ تنظیمات عوض کنید (هر خط یک لینک)
- داده‌ها: `%APPDATA%\GlowRay` (config.json تولیدشده، کش ساب، هسته)

## ساختار
```
src/main.js            مدیریت اتصال، IPC، تری
src/core/parser.js     تبدیل لینک‌های vless/vmess/trojan/ss/hy2/tuic به outbound
src/core/config.js     ساخت کانفیگ sing-box (1.12+)
src/core/singbox.js    اجرای/دانلود هسته
src/core/sysproxy.js   پروکسی سیستم ویندوز (رجیستری + WinINet)
src/core/clash.js      Clash API برای تست تاخیر، سوییچ سرور، ترافیک
src/renderer/*         رابط کاربری
```
